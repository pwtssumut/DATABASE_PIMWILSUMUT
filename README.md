# Database Pimwil VIII Tapak Suci Sumut

Situs database organisasi (Pimda, cabang, unit latihan, pengurus, anggota).
Data disimpan di Supabase, bukan di repo ini. Repo ini hanya berisi tampilan situs.

Sebelum situs berfungsi, isi `config.js` dengan Project URL dan Publishable key dari Supabase
(Project Settings > API). Jangan pernah memakai kunci `service_role` atau `secret`.
